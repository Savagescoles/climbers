# Shelton Climbers MV Playbook

Static website package prepared for GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload every extracted file and the `plays` folder to the repository root. The page also contains embedded backups, so `index.html` can display the design and all 20 plays by itself.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.

GitHub will provide the public website address after deployment completes.
